🔧 MXD-VehicleRepair | FiveM QBCore

MXD-VehicleRepair is a lightweight and optimized FiveM vehicle repair script built specifically for the QBCore framework. This script allows players to repair their vehicles easily using commands or usable items, while keeping performance and simplicity in mind.

The resource is fully open-source and available on GitHub, making it easy to customize, improve, and integrate into any QBCore server.

✨ Features

✅ QBCore framework support

🛠️ Vehicle repair using command or item

⚡ Zero lag & optimized performance

🔒 Job / permission support (optional)

⚙️ Easy configuration

🧩 Clean & well-commented code

🌍 Open-source (GitHub)

🧰 Requirements

QBCore Framework

Basic FiveM knowledge for customization

📦 Installation

Download or clone the repository from GitHub

Place the resource inside your resources folder

Add ensure mxd-vehiclerepair to your server.cfg

Configure settings as needed and restart the server
